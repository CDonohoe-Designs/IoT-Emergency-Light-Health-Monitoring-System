
# Data

This folder contains redacted sample test data from my IoT Emergency Light Health Monitoring System prototype.

The data shows the type of information produced by the system during emergency-light discharge testing and cloud reporting.

## Included File

| File | Description |
|---|---|
| `Example_Test_Data_Redacted.pdf` | Redacted example of test/reporting data generated by the prototype system |

## Data Purpose

The prototype recorded information such as:

- Device identity
- Customer/location reference
- Test type
- Date and time
- Light-level reading
- Mobile signal strength (RSSI)
- Pass/fail style result information

## Privacy Note

The original dataset contained project-specific identifiers. The version included here has been redacted for public portfolio use.
