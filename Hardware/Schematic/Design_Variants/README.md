
# Design Variants

This folder contains alternative schematic/design variants for the Emergency Exit Light Health Checker.

The files here are included to show design exploration and future integration ideas. They do not represent the as-built prototype version of the board.

## Included Files

| File | Description |
|---|---|
| `Schematic_ESP32_SIM800C_OnPCB_Concept.pdf` | Concept schematic where I explored integrating the SIM800C modem, SIM card holder and ESD protection directly onto the PCB. |

## Note

The as-built prototype used a plug-in SIM800L module and is documented in the main `Hardware/Schematic/` folder.
