This folder contains schematic evidence for the Emergency Exit Light Health Checker hardware.

The design includes the ESP32 controller, SIM800L/GPRS modem interface, BH1750 digital light sensor, UART programming header, external I2C/GPIO connector, relay control and the main power sections used by the prototype.

## Included Files

| File | Description |
|---|---|
| `Schematic_ESP32_AC_SIM800L_V1.0.pdf` | Main schematic showing the ESP32 digital circuits, SIM800L modem interface, BH1750 light sensor, relay control, AC/DC power conversion, 3.3 V ESP32 rail and 4.1 V modem rail. |

## Notes

This schematic is included as portfolio evidence of the electronic design work carried out during the prototype stage. It is not intended as a certified safety design or installation guide.
